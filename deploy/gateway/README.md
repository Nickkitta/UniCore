# Подключение UniCore через свой домен

Сначала сравните один телефон без VPN через Wi-Fi и мобильную сеть: откройте `/auth/v1/settings` на текущем домене проекта в браузере — ответ про отсутствующий API key означает, что DNS, TLS и маршрут работают. В новой версии кнопка «Проверить связь с сервером» в форме входа проверяет тот же сервис с публичным ключом. Если настройки доступны, но вход не работает, отдельно проверьте вход, загрузку ленты и фото — смена домена может не понадобиться

Для альтернативного маршрута понадобится собственный домен и сервер, доступный с проблемной сети и способный подключаться к текущему проекту. Учётные записи, JWT, правила доступа и данные остаются в прежнем проекте. Шлюз завершает TLS и передаёт запросы авторизации, поэтому используйте только свой доверенный сервер и не включайте логирование заголовков, тел или подписанных URL

1. Направьте DNS поддомена API на сервер и откройте входящие 80 и 443
2. Установите Caddy 2 и скопируйте соседний Caddyfile. В окружении службы задайте `UNICORE_API_DOMAIN` (свой поддомен без https) и `UNICORE_PROJECT_HOST=zusvsbnyfiltflvmywum.supabase.co`. Секретные ключи шлюзу не нужны
3. В окружении этих переменных выполните `caddy validate --config /etc/caddy/Caddyfile --adapter caddyfile` и перезагрузите службу. Повторите проверку `/auth/v1/settings` на своём домене с того же телефона
4. Для разработки укажите `EXPO_PUBLIC_API_BASE_URL=https://ваш-поддомен` в `apps/mobile/.env.local`; для APK задайте переменную в окружении EAS preview и пересоберите клиент. Проверяйте вход, повторный запуск с сессией, ленту, изображения и чат без VPN
5. Для возврата к прямому маршруту удалите переопределение и пересоберите приложение. Перенос БД, смена ключей и отключение RLS не требуются

## Обновление базы и карты

После трёх миграций от 12 ноября примените `supabase/migrations/202611200001_event_rooms.sql` один раз в SQL Editor. Старые профили сохраняются; новые сочетания института и группы должны быть в `public.unicore_groups`. Если миграция уже выполнена, для дополнения справочника выполните только блок `insert into public.unicore_groups(faculty,group_name) … on conflict do nothing` из её начала

Яндекс Карты показывают адрес выбранной точки при доступном геокодере. Сохранение адреса геокодера в поле события включайте через `EXPO_PUBLIC_STORE_MAP_ADDRESS=true` только если это допускает лицензия. Без этой настройки пользователи выбирают точку и вводят своё название места. См. https://yandex.ru/dev/commercial/doc/ru/
